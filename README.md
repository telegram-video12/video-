# הספרייה שלי: סדרות וסרטים מטלגרם

אתר פרטי שאוסף את הסדרות והסרטים מקבוצות וערוצי הטלגרם שלך, מסדר אותם בספרייה (סדרה ← עונות ← פרקים), ומנגן אותם ישירות בדפדפן.

- **מעקב צפייה:** האתר זוכר בדיוק איפה עצרת בכל פרק או סרט, ובפעם הבאה ממשיך משם.
- **"המשך צפייה":** בדף הבית רואים מה באמצע ומה הפרק הבא בכל סדרה.
- **מעבר אוטומטי לפרק הבא** בסוף כל פרק, עם ספירה לאחור של 10 שניות.
- **סימון ידני** של פרקים כנצפו או כלא נצפו.
- **זיהוי אוטומטי** של שם הסדרה, העונה והפרק מתוך הכיתוב או שם הקובץ. נתמכים: `S02E05`, `2x05`, `עונה 2 פרק 5`, `ע2 פ5`, `פרק 5`.
- **פוסטרים ותקצירים בעברית** מ-TMDB (רשות).
- **מצב עריכה** לתיקון זיהוי שגוי: שינוי עונה או פרק, העברה לסדרה אחרת, איחוד סדרות, הסתרת קבצים.
- **הגנה בסיסמה.** עובד גם בטלפון.

## איך זה עובד

```
קבוצות טלגרם ──(החשבון שלך, MTProto)──> השרת (Python) ──> הדפדפן
                                        │
                                        └─ library.db: הספרייה + איפה עצרת
```

הסרטונים **לא** מורדים למחשב. השרת מושך מטלגרם רק את החלק שהנגן צריך באותו רגע, ולכן אפשר גם לקפוץ קדימה ואחורה.

## התקנה (פעם אחת)

### 1. התקנת Python
להוריד מ-https://www.python.org/downloads/ (גרסה 3.10 ומעלה).
ב-Windows חשוב לסמן בהתקנה **"Add Python to PATH"**.

### 2. קבלת מפתח API של טלגרם
1. להיכנס ל-https://my.telegram.org עם מספר הטלפון שלך.
2. ללחוץ על **API development tools**.
3. למלא טופס קצר (שם האפליקציה לא משנה).
4. להעתיק את **api_id** ואת **api_hash**.

### 3. הגדרות
להעתיק את הקובץ `.env.example` לקובץ בשם `.env` ולמלא בו:

```ini
TG_API_ID=1234567
TG_API_HASH=abcdef...
SITE_PASSWORD=הסיסמה-שתבחר-לאתר
TMDB_API_KEY=            # רשות: מפתח חינמי מ-themoviedb.org לפוסטרים
```

### 4. הפעלה
- **Windows:** לחיצה כפולה על `start.bat`
- **Mac / Linux:** `./start.sh`

בהפעלה הראשונה הסקריפט מתקין את מה שצריך ומבקש להתחבר לטלגרם: מספר טלפון בפורמט `+972...`, הקוד שמגיע בטלגרם, וסיסמת אימות דו-שלבי אם יש.

אחר כך פותחים בדפדפן: **http://localhost:8000**

### 5. בחירת קבוצות
באתר נכנסים ל-**⚙ הגדרות**, מסמנים את הקבוצות והערוצים שמהם רוצים לאסוף סדרות וסרטים, ולוחצים **שמור וסרוק**.
מכאן האתר סורק אוטומטית כל 30 דקות ומוסיף פרקים חדשים.

## צפייה מהטלפון או מהטלוויזיה בבית
כשהמחשב דולק והאתר רץ, אפשר להיכנס מכל מכשיר באותה רשת Wi-Fi:
`http://<כתובת-ה-IP-של-המחשב>:8000`

את הכתובת מוצאים ב-Windows עם הפקודה `ipconfig`, בשורה IPv4 Address.

## הפעלה ידנית (בלי הסקריפטים)
```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt     # Windows: .venv\Scripts\pip
python -m app.login                           # פעם אחת בלבד
python -m app                                 # מפעיל את האתר
```

## הערות חשובות
- **פורמטים:** קבצי MP4 (H.264) מתנגנים בכל דפדפן. קבצי MKV מתנגנים בדרך כלל ב-Chrome וב-Edge. קבצי HEVC/H.265 עלולים לא להתנגן. במקרה כזה מופיע באתר כפתור הורדה.
- **פרטיות:** הקובץ `data/telegram.session` הוא בעצם גישה לחשבון הטלגרם שלך. אל תשתף אותו ואל תעלה אותו לשום מקום. הוא כבר מוחרג מ-git.
- **הקובץ `data/library.db`** שומר את הספרייה ואת היסטוריית הצפייה. כדאי לגבות אותו מדי פעם.
- **זיהוי שגוי:** אם סדרה זוהתה לא נכון, נכנסים אליה ← **✏️ עריכה**. משם אפשר לתקן עונה או פרק, להעביר פרק לסדרה אחרת, לאחד שתי סדרות, או לחבר ל-TMDB הנכון (מדביקים את הקישור מ-themoviedb.org).

## מבנה הפרויקט
```
app/
  main.py       שרת האתר וה-API (FastAPI)
  telegram.py   חיבור לטלגרם, סריקה והזרמת וידאו
  parser.py     זיהוי שם, עונה ופרק מכיתוב או שם קובץ
  db.py         מסד הנתונים (SQLite) ומעקב צפייה
  tmdb.py       פוסטרים ותקצירים
  login.py      התחברות חד-פעמית לטלגרם
  static/       האתר עצמו (HTML/CSS/JS)
tests/          בדיקות אוטומטיות (pytest)
```
