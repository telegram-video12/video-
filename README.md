# הספרייה שלי: סדרות וסרטים מטלגרם, בפלאפון

אתר פרטי שרץ **על הפלאפון שלך** (אנדרואיד). הוא אוסף את הסדרות והסרטים מקבוצות הטלגרם שלך, מסדר אותם (סדרה ← עונה ← פרק), ומנגן אותם.

- **זוכר איפה עצרת** בכל פרק וסרט, וממשיך משם.
- **"המשך צפייה"** בדף הבית: מה באמצע ומה הפרק הבא.
- **מעבר אוטומטי לפרק הבא.**
- **סימון ידני** של פרקים כנצפו.
- **זיהוי אוטומטי** של שם, עונה ופרק: `עונה 2 פרק 5`, `ע2 פ5`, `S02E05` ועוד.
- **פוסטרים ותקצירים בעברית** (רשות).
- **מצב עריכה** לתיקון זיהוי שגוי.

---

## מדריך התקנה בפלאפון (פעם אחת, כ-15 דקות)

### שלב 1: התקנת Termux
Termux היא אפליקציה חינמית שמריצה את האתר על הפלאפון.

> ⚠️ **לא מ-Google Play.** הגרסה שם ישנה ולא עובדת.

1. בפלאפון, פתח בדפדפן: **https://github.com/termux/termux-app/releases/latest**
2. גלול ל-**Assets** והורד את הקובץ שהשם שלו מכיל **`arm64-v8a`** וגמור ב-`.apk`.
3. פתח את הקובץ שהורד. אם אנדרואיד שואל, אשר **"התקנה ממקורות לא ידועים"** לדפדפן.
4. פתח את Termux ותן לו דקה לסיים את ההכנה הראשונית, עד שמופיע הסימן `$`.

### שלב 2: התקנת האתר
העתק את השורה הזו, הדבק ב-Termux (לחיצה ארוכה על המסך ← **Paste**) ולחץ Enter:

```
curl -fsSLo i.sh https://raw.githubusercontent.com/telegram-video12/video-/HEAD/install-termux.sh && bash i.sh
```

ההתקנה לוקחת כמה דקות. אם Termux שואל שאלה, לחץ **Enter**.
בסוף יופיע: **✓ ההתקנה הסתיימה!**

### שלב 3: הפעלה
ב-Termux הקלד ולחץ Enter:
```
tv
```
הדפדפן ייפתח לבד על האתר. אם הוא לא נפתח, היכנס ידנית ל-**http://localhost:8000**

### שלב 4: הגדרה ראשונה (באתר עצמו)
1. **בחר סיסמה לאתר.**
2. **מפתחות API:** האתר יסביר איך לקבל אותם מ-my.telegram.org ולהדביק אותם.
3. **התחברות לטלגרם:** מספר טלפון, ואז הקוד שמגיע באפליקציית טלגרם.
4. **סמן את הקבוצות** שבהן יש סדרות וסרטים ולחץ **שמור וסרוק**.

סיימת! 🎉

### טיפ: אייקון במסך הבית
כשהאתר פתוח ב-Chrome: ⋮ (תפריט) ← **הוסף למסך הבית**.

## שימוש יומיומי
1. פותחים את **Termux** ומקלידים `tv`.
2. האתר נפתח. צופים 🍿
3. כדי לחזור לאתר בלי להפעיל מחדש: האייקון במסך הבית, או http://localhost:8000

כל עוד Termux פתוח ברקע, האתר עובד. כשסוגרים את Termux, האתר נכבה. ההתקדמות כבר שמורה.

**כדי ש-Termux לא ייסגר באמצע סרט:** הגדרות הפלאפון ← אפליקציות ← Termux ← סוללה ← **ללא הגבלה**.

## עדכון לגרסה חדשה
כשאני מוסיף שיפורים, ב-Termux:
1. אם האתר פועל, עצור אותו (CTRL+C, או סגור ופתח מחדש את Termux).
2. הקלד: `tv-update`
3. אחר כך: `tv`

## בעיות נפוצות
| בעיה | פתרון |
|---|---|
| `tv: command not found` | ההתקנה לא הסתיימה. הרץ שוב את הפקודה משלב 2 |
| האתר לא נפתח | בדוק ש-Termux פתוח ושהקלדת `tv` |
| בכניסה ל-my.telegram.org מופיע "ERROR" | כבה VPN, או נסה בדפדפן אחר |
| הסרטון לא מתנגן | קבצים בפורמט HEVC/H.265 לא תמיד נתמכים. נסה ב-Chrome |
| סדרה זוהתה לא נכון | בדף הסדרה ← ✏️ עריכה |

## פרטיות
כל המידע נשמר **רק בפלאפון שלך**, בתיקייה `~/tgvideo/data`. הקוד באינטרנט לא מכיל שום סיסמה או מפתח.
האתר נגיש רק מהפלאפון עצמו, ולא ממכשירים אחרים ברשת.

## למפתחים
```
app/
  main.py          שרת + API (Starlette, Python טהור)
  telegram.py      חיבור לטלגרם, התחברות, סריקה והזרמה
  crypto_boost.py  פענוח מהיר דרך OpenSSL באנדרואיד
  parser.py        זיהוי שם / עונה / פרק
  db.py            SQLite: ספרייה ומעקב צפייה
  tmdb.py          פוסטרים ותקצירים
  config.py        הגדרות (data/config.json)
  static/          ממשק האתר
install-termux.sh  סקריפט התקנה לאנדרואיד
tests/             בדיקות (pytest)
```
הרצה במחשב: `pip install -r requirements.txt && python -m app`
